# VirtualQueue v0.1.0 — initial software archive

Initial public research-software release for the synthetic FIFO packet-feedback
and telemetry-shift experiments accompanying the JTIT manuscript.

Included: event-time simulator, causal report features, scenario-held-out
baseline experiments, 10 repeated synthetic traces (selected methods), CSV/JSON
artifacts, plotting scripts and timing sanity tests.

Not included: real 5G NR measurements, external validation, proprietary JTIT
LaTeX class or logos, reviewer-only files, privileged account credentials.

Validation status: synthetic pilot only. Readers should distinguish the original
four-fold experiment and later 10-trace repetition from the earlier exploratory
three-split files retained for traceability.

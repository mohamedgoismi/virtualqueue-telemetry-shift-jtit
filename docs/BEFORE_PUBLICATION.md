# Publication checklist (mandatory human review)

- [ ] Confirm that all five manuscript authors approve being named as creators
      of this **software** release, their order, names and affiliations.
- [ ] Confirm publication rights and acceptance of the **MIT license** for the
      original code and generated synthetic artifacts. If not approved, change
      `LICENSE` and `CITATION.cff` before publication.
- [ ] Decide whether code publication with named authors affects the journal's
      double-blind review; consult JTIT editorial guidance as needed. Cite
      the record in the anonymous manuscript without unnecessarily naming
      individual creators in the blind text.
- [ ] Do not include publisher-owned LaTeX class/branding, private credentials,
      or third-party network datasets in this code repository.
- [ ] Check and rerun the independent timing tests on the final checkout.
- [ ] Validate that the artifact set is accurately labeled as **synthetic**.
- [ ] Complete JTIT AI-use, conflicts, funding and licensing declarations
      truthfully; coauthors need to approve the declarations.
- [ ] Publish public GitHub repository; **enable it in Zenodo before creating
      the first GitHub release** (see official guide).
- [ ] Publish GitHub release v0.1.0, confirm it appears in Zenodo and copy its
      actual DOI to the final manuscript.
- [ ] Re-run the tests and upload an updated release if any content changed.

This archive does not claim that a DOI, GitHub repository, scientific external
validation or journal submission already exists.

# VirtualQueue — delayed packet feedback and latency-violation experiments

**Software release candidate v0.1.0.** Research code and archived results accompanying
*“Delay-Violation Alarms with Incomplete Packet Reports: Scenario-Held-Out and Independent-Trace Queueing Tests”*.

**Scope.** This is an explicitly **synthetic single-server FIFO** experiment. The
72 scenario configurations mimic variations in offered load, but this repository
contains **no real 5G NR, RAN, base-station or field measurements**. The public
Zenodo 5G NR and DETERMINISTIC6G datasets cited in the manuscript have not been
used for validation in this archive.

## What is included?

| Directory | Contents |
| --- | --- |
| `code/` | Event-time simulator, queue baselines, four-fold experiments, ten-trace repetition, checks |
| `results/` | Original CSV/JSON artifacts, including complete synthetic trace, out-of-fold predictions and aggregate tables |

| `paper/references.bib` | Bibliography; paper PDF and the publisher's proprietary journal template are **not** distributed here |
| `tests/` | Fast tests for timing invariance, outputs, group disjointness, and artifact completeness |

### Main findings as archived (not newly rerun for the GitHub package)

For one reference synthetic trace evaluated with four disjoint scenario folds,
mean average precision was approximately 0.728 (context-only logistic regression),
0.948 (outstanding-report count), and 0.964 (history logistic regression).
The ten independent synthetic-generator traces provided additional replication
for **those three methods only**. They do not establish external-network performance.

Several derived CSV files are earlier exploratory protocols. Follow the
[results provenance guide](docs/PROVENANCE.md) rather than combining numbers
from incompatible three-split and four-fold experiments.

## Reproduce the basic tests

Python **3.10+**, preferably 3.11 on Windows, Linux or Kaggle.

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python code/test_temporal_integrity.py
python -m unittest discover -s tests -v
```

### Re-run the main experiments

The commands below **overwrite files in `results/`**. Commit or save a copy of
these archived data first. Runtime depends on CPU; a GPU is not required.

```bash
python code/reviewer_major_revision_experiments.py --out results
python code/reviewer_round3_experiments.py --repeat 10
python code/round3_threshold_sensitivity.py
```

Use `--help` to check the arguments before a full run. Repeated traces use generator seeds
`20261100` to `20261109`, which are *experiment labels*, not timestamps.
For the static archived results and complete execution protocol, see
[docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md).

## Scientific limitations

- One simulator family, capped workload and simplified packet reporting;
  37/72 original configurations have no latency violations.
- No validation on independent 5G NR or field packet data.
- Some telemetry variants, HGB comparisons, and threshold analyses were
  evaluated on a single synthetic trace; see `docs/PROVENANCE.md`.
- Alarm budgets are retrospective rankings, not deployed alert policies.
- Some queue-state reconstruction variants used privileged queue labels at
  **training** time only; distinguish those variants from label-free baselines.
